TL;DR

Believable behavior comes from managing time and state around the model.

An LLM can make a character sound believable once. This paper adds a notebook, selective attention, reflection, and planning so the character can carry a day forward.

WHERE THIS BECOMES USEFUL

  • GamesCharacters who remember what you did, not just answer the latest line.
  • Social worldsA way to watch news, invitations, trust, and plans move through a group.
  • What you could buildA small model of a team or community before changing the real one.

FIRST PRINCIPLES

What must be true before a world can behave?

Strip away the language model for a moment. These are the basic conditions that make a simulated life possible.

  1. 01

    The world has facts

    There is a clock, a place, other people, and rules about what can happen.

    world
  2. 02

    A person sees only part of it

    Isabella does not know everything in town. She knows what she noticed or what someone told her.

    view
  3. 03

    Experience becomes memory

    Important events are saved so the past can affect a later choice.

    memory
  4. 04

    Memory changes the next action

    The person uses a few relevant memories to decide what to do now.

    choice
  5. 05

    Actions create new facts

    A conversation, arrival, or missed appointment changes what everyone else can notice next.

    consequence
01

The architecture is the argument.

The paper’s key move is a loop around the language model: keep a record, choose what matters, make meaning, make a plan, act, and observe the consequences.

SELECTED COMPONENT

Retrieve what matters now.

The full history is too large and too distracting to place in every prompt. Retrieval selects a compact set of memories that can inform the current decision.

  • Use the current situation as a query.
  • Balance recency, importance, and relevance.
  • Pass only the top-ranked memories onward.

Attention over an external, persistent notebook.

02

Isabella may have thousands of observations. The question decides which few records become “present” for the next answer.

03

Reflection turns events into identity.

An observation records an event. A reflection turns several events into a reusable idea about a person, a relationship, or the world.

Events → patterns → a usable story about the self. Because reflections are stored as memories, the tree can keep growing upward.

04

06

How we would build it.

Start with a world that works. Add intelligence only where it helps us see behavior change.

  1. 01

    Make the world before the intelligence

    Create one place, a clock, a few activities, and one event. Make sure time and consequences work without a language model.

  2. 02

    Give one person a notebook

    Save what they saw, what they want, and what happened to them. This is the beginning of continuity.

  3. 03

    Let the person choose

    Show the person the current situation and a few relevant memories. Ask for one possible next action, then check that action against the world’s rules.

  4. 04

    Let consequences spread

    Add four more people. A conversation should create a new fact that another person can notice, remember, and act on.

  5. 05

    Add patterns later

    Only after the basic loop works, add daily plans and broader reflections about relationships, habits, and goals.

STOP HERE FIRST

If we cannot explain one surprising action from a person’s memories, goals, and surroundings, we should not add more people or more features.

07

The result—and the boundary.

When evaluators ranked five versions of the agent, the full architecture came out on top. That supports the value of the scaffold in this setting, not a claim of general intelligence.

READ IT CRITICALLY

Believable means the behavior reads as plausible to evaluators.

Emergent means the event was not scripted step by step.

Neither establishes consciousness, human-level understanding, or robust long-term autonomy.

The question

An LLM can answer plausibly in the moment, but without continuity it can forget an election, flatten a person into a stereotype, or eat lunch twice. The paper treats memory and time as an architecture problem, not just a prompting problem.

What the experiment shows

In Smallville, 25 agents accumulate experiences, form relationships, diffuse information, and coordinate around a Valentine’s Day party. Human evaluators preferred the full architecture over versions with reflection, planning, or memory access removed.

What it does not show

The result is a believable simulacrum in a small, two-day sandbox—not consciousness, human-level understanding, or robust long-term autonomy. Retrieval failures, hallucinated embellishments, over-polite dialogue, missing world norms, and inference cost remain visible boundaries.
