A round cannot close until the tests are green on that exact head, so every fold pays the full test wait before the next verdict can start.

Hours per round is the week’s average hours from open to merge divided by its average reviewer rounds. Bar length is that average; the darker block is one test run on one push, drawn to scale against it.

05

What broke, and what it became

Four failures from one week. Each one is now a line in the log, checked before the next pull request opens.

What broke
House law
An acknowledgement posted before the fix triggered a second review at the unchanged head.
No comments between a review round and the fold push.
A defect our own pre-push review had reproduced was waved off as disclosed. The reviewer cited the same lines next round.
Anything reproduced before the push is fixed before the push.
One fix closed the one call site the reviewer flagged. The same rounding rule resurfaced in three paths.
Fix the class, not the leaf. Grep every other call site before folding.
The review matrix tracked whether the account existed, never what its ledger already held.
Enumerate the target’s prior state before the first fix.
Four rounds, four rules.

A rule only counts once it is written where the next pull request will read it.
