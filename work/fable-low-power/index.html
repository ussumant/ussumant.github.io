Fable Low Power Mode

A Claude Code skill that watches live usage windows and shifts repetitive execution to cheaper workers when frontier-model quota gets tight.

role
Independent build
fields
AI tools · workflow design · open source

The problem

My best model was spending limited quota on file reads, searches, builds, tests, and repetitive edits—the work around the decisions rather than the decisions themselves.

The mechanism

Low Power Mode reads the 5-hour and 7-day usage percentages already present in Claude Code's statusline payload. At a threshold, it keeps the frontier model focused on planning, judgment, review, and final decisions while subagents handle execution.

Observed result

For the same working pattern, my Fable allowance moved from roughly two days to at least five. That is a personal workflow measurement, not a universal benchmark.
