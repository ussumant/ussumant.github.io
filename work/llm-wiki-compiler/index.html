LLM Wiki Compiler

A Claude Code plugin that compiles large Markdown knowledge folders into smaller topic articles, following the LLM knowledge-base pattern described by Andrej Karpathy.

role
Independent build
fields
knowledge systems · Claude Code · open source

The problem

Agent sessions were repeatedly loading large, overlapping context files. The useful knowledge was there, but the shape was expensive and difficult to navigate.

What it does

The compiler groups source notes by topic, synthesizes them into linked wiki articles, and gives agents a smaller map from which to pull only the context they need.

A concrete run

One corpus of 383 notes compiled into 13 topic articles. The repository had 311 GitHub stars when this entry was updated on 12 August 2026.
