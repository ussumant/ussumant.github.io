Cache Audit

A focused audit skill that checks a Claude Code setup against prompt-caching rules and returns a scored report with specific fixes.

role
Independent build
fields
developer tools · Claude Code · open source

Why

Prompt caching failures are expensive but mostly invisible. A setup can look normal while volatile context, ordering, or configuration choices keep invalidating the reusable prefix.

What it does

Cache Audit inspects the setup, explains which rule each issue violates, and turns the diagnosis into concrete changes rather than generic token-saving advice.
